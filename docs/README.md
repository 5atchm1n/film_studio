# Docs — how the studio came to be

The history of "AI - Retrieving dynamic data" (11–13 Oct 2026) and of film_studio built from it (13 Oct).
Copied from the read-only reference project `../visuels_mcp_harness/` in Phase 6; paths inside the copied files
(`_archives/…`, `../film.py`) refer to that folder.

| File | What |
|---|---|
| `PROCESS_LOG.md` | Every request made for the first film, verbatim, in order (the raw source of truth) |
| `VERSIONS.md` | Version map: generations 1–4 (the first film) and 5 (film_studio, phase by phase) |
| `frames/INDEX.md` | Contact sheets of every version (`NN_<version>.png`, `NN_<version>_chapters.png`) |
| `AUDIT.md` | Code audit of the first film before the studio |
| `PLAN_FILM_STUDIO.md` | The plan (phases 0–7) this repo executes |
| `PROMPT_FILM_STUDIO.md` | The clean-context kick-off prompt that started film_studio |
| `BLOG_BACKBONE.md` | Structure + evidence for a future blog post (prose TODO) |
| `history/ETAT_PROJET.md` | Project state file of the first film (French), superseded by `films/<name>/STATUS.md` |
