# Self-check before showing anything

## Every render
- [ ] Ran without errors; duration plausible; chapters present, in order, translated.
- [ ] Looked at the sheet (`sheet.png` / `studio sheet <video>`) — actually looked, not just generated.
- [ ] Around each change: `studio frames <video> --at …`, frames looked at.
- [ ] Nothing overlaps or leaves the frame; text readable at 480p (readable on the sheet tile).
- [ ] Dimmed things are dim; lit things lit once (no stacked copies); one path lit per call.
- [ ] Keywords only; no invented precise figures.

## Stills (G2)
- [ ] Each beat shows one idea; the act's key image (brief.md) is recognisable.
- [ ] Same thing = same id across beats (it will morph at G3).
- [ ] `--lang fr` stills: no English left, nothing overflowing.

## Motion (G3/G4)
- [ ] One thing changes at a time; transitions read as cause → effect.
- [ ] The motion ends exactly on the next still (the engine snaps to it: a jump at the end means a mismatch).

## Before the end of a step
- [ ] Kit / engine / pipeline touched → `studio regress ai_retrieving_dynamic_data` IDENTICAL (EN + FR).
- [ ] STATUS.md updated; committed.
- [ ] Final? Only with the user's explicit validation.
