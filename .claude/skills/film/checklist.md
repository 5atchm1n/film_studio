# Self-check before showing a render

- [ ] Render finished without errors; duration plausible; chapters present and in order.
- [ ] `studio sheet <video>` (grid) and `studio sheet <video> --chapters <chapters.json>` looked at.
- [ ] For each changed shot: `studio frames <video> --at …` around the change, frames looked at.
- [ ] Nothing overlaps or leaves the frame; text readable at 480p; no stray objects left on screen.
- [ ] Dimmed things are dim; lit things are lit once (no stacked copies); one path lit per call.
- [ ] Keywords only; no invented precise figures.
- [ ] Legacy film touched? `studio regress ai_retrieving_dynamic_data` → IDENTICAL (EN + FR).
- [ ] Final? Only with the user's explicit validation.
